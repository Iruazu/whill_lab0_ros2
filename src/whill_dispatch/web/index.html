画面の見かた（簡易ガイド）
  • 名前付きの目的地。タップか上のリストで選択できます
  • 選択中の目的地（黄色に変わります）
  • 地図をタップして指定した目的地（道路の白い部分のみ指定可）
  • 車両の現在位置
  • 走行予定の経路（走行中のみ表示）
  • 「行く」「呼ぶ」はジョブの種別ラベルです（現時点ではどちらも 「選んだ目的地へ移動する」同一動作）
  • 「実行」でジョブを発行し、「キャンセル」で走行中のジョブを中止します
  • 状態: IDLE=待機 / QUEUED=受付済 / ACTIVE=走行中 / SUCCEEDED=到着 / ABORTED=中断 / CANCELED=取消
  • 自己位置 fitness: 自己位置推定の残差（小さいほど良好。 1.0 超が約 2 秒続くと安全装置が停止させます）
  • バッテリ: 車両の残量 (%)
