# WHILL CR2 実機スタック 現状報告

2026-11-27 · Iruazu（調査と記述は Claude Code、照合の範囲は末尾の「根拠一覧」）

## 総括

現行の main は起動し、低速（0.30 m/s）で自律走行できる。ただし、研究の実験基盤として「品質を確認できた」と言えるのは LiDAR の仰角表と取り付けの z・roll・pitch、および NDT が追従を保つことまでで、その上の層は修正前の値のまま再検証されていない。

**確認できたこと**

- LiDAR の仰角表の誤り（±15° 用を ±10° 機に使用）と TF の誤り（pitch +8.99°）は、2026-11-13 に修正された。新しい値は屋内と屋外の実測で裏付けられている。
- 地図 campus-m8 は補正後の点群から作り直された。2026-11-27 の実走行では、NDT は全区間で追従を保った（fitness 最大 0.160、しきい値 1.0）。
- 自動試験は全件通る（54 件と 217 件）。ホスト環境は文書どおり。

**確認できていないこと**

- **停止距離と反応時間は、一度も測られていない。** 停止指令は速度平滑化を通る。
- **絶対位置の誤差は測られていない。** fitness は位置の正しさを示さない。
- LiDAR の yaw、IMU の取り付け角（2026-07-10 以降）、車輪オドメトリのスケール、EKF の誤差、車体の後端と幅、カメラの深度は、実測がないか古い。
- `/scan` の高さ帯、failsafe のしきい値、Nav2 の外形と追従の設定は、すべて LiDAR 修正の前に調整した値のままである。

**現行構成の実走行で起きたこと（2026-11-27）**

goal 5 件のうち 3 件が成功、2 件は failsafe の Layer D が解けずに進めなくなり取消した。記録の解析では、車体の前の角が地図上の障害物まで 0.20 m に寄っている。Nav2 は車体を半径 0.45 m の円として扱っており、実測の前端（車軸から 0.72〜0.75 m）はその外にある。

**安全層に残る穴**

- `/scan` が途絶えても Layer D は止めない（修正の PR #203 が未マージ）。
- 起動時から届かない入力は警告だけで止めない（既定）。
- 停止域内で高さ約 0.43 m 未満の物は LiDAR に映らない（計算値）。
- 「1.0 m 未満の点は来ない」という設計上の前提が、コードと食い違う。

**マイルストーンの完了条件**

ロードマップ自身の完了条件を満たすのは M8-0 だけである。M8-1 は #143・#146・#148・#149 が開いている。M8-2 は屋外での 1 周が未達。M8-3 は #192 以外がすべて開いている。M8-4 と M9 は未着手。

実機は 3 つの launch で動く。既定の地図は campus-m8、Nav2 の占有格子は candidate（154w で広げた版）。以下は main の launch と設定を読んだ結果（確度 B）で、launch 引数は今回 `--show-args` で評価した。

### データの経路

1. `/velodyne_points` は NDT ローカライザ（地図は `docs/maps/campus-m8/static.pcd`）と Patchwork++ に入る。
2. Patchwork++ の地面除去後の点群は LaserScan `/scan` に変換され、Nav2 の local costmap と failsafe の Layer D に入る。
3. EKF は `/whill/odom` の速度と `/imu/data_rep145` を 30 Hz で融合し、`odom→base_link` を出す。NDT はその出力を予測に使い、`map→odom` を出す。
4. 速度指令は 3 系統で twist\_mux に入る。優先度は failsafe 100、teleop 50、Nav2 10。
5. twist\_mux の出力は velocity\_smoother を通って WHILL ドライバに届く。failsafe のゼロ指令も smoother を通る。

### 実測がない、または古い項目

- **IMU の取り付け角**：最後の測定は 2026-07-10 朝。同日の走行後の確認は ax +1.331、ay −0.577 で、台帳の許容 ±0.05 m/s² を外れていた。台帳も「計算し直すべきだったが、していない」と書く。以後の測定記録はない。
- **ジャイロの符号**：Issue #56 は「暫定判定。rotate 試験で再確認する」とした。再確認の記録は見つからない。
- **オドメトリの距離スケール**：2026-06-14 の「約 2 m 前進、1 回、メジャー計測なし」だけ。Issue #37 の 10 m 直進の受入は記録がない。
- **LiDAR の個体差**：仰角表は汎用値で、個体の工場校正ファイルはリポジトリにない。
- **復帰手順（水平器とテープ）の再現性**：台帳に「未測定」とある。
- **着座時の姿勢**：座ると対床 pitch が約 −0.75° 変わる。測定は 1 回。

### 新しい TF で再検証されていない上位の値

`/scan` の高さ帯（`min_height: 0.05`、`max_height: 1.6`）と failsafe の Layer C・D のしきい値は、旧 TF・旧仰角表のもとで 2026-07-15 に調整した値のままである。再検証は #191 にあり、コメント 0 件で未着手。

### 地図作成用の LiDAR–IMU 相対姿勢

campus-m8 の作成に使った GLIM の `T_lidar_imu` は、並進が noetic の値、回転が「LiDAR pitch −0.5°」を仮定した値である。この −0.5° は旧仰角表の点群から推定された。現在の TF から計算した相対姿勢とは pitch で約 0.9° 違う（調査時の計算）。campus-m8 の README は「imu\_link か velodyne の TF、または両方が実物とずれている可能性がある。この地図では決めていない」と書いている。

### 校正台帳の中の食い違い
