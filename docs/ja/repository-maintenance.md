## 実装の制約

- failsafeの初回未受信watchdogはエラー通知であり、入力未受信時の起動禁止を保証しない。
- Layer Dは前方±30°・1〜2mの点を検知する。人の分類・後方検知・全周監視はない。
- safetyのゼロ指令もvelocity_smootherを通る。停止距離は実機で確認する。
- dispatchは認証・永続キュー・複数車両管理を持たない。
- 手動中のsafety優先停止は、過去の未検証注記を解消する証跡が必要。
- 静的TFには旧校正・概算値がある。機器の再固定や交換後は現物と台帳を照合する。

実機での1回の配車成功を、全経路・全停止機能の受入完了とは扱わない。
