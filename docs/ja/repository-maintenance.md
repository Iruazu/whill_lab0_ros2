## 実装上の制約

- failsafeの初回未受信watchdogはエラー通知であり、入力未受信時の起動禁止を保証しない。
- Layer Dは前方±30°・1〜2mの点を検知する。人の分類・後方検知・全周監視ではない。
- safetyのゼロ指令もvelocity_smootherを通る。実測停止距離は別途検証する。
- dispatchは認証・永続キュー・複数車両管理を持たない。終了だけでNav2 goalの取消を保証しない。
- 手動救出中のsafety優先停止には過去の未検証注記が残る。完了を示す証跡が必要。
- 静的TFには旧校正・概算値がある。機器の再固定・交換後は台帳と現物を照合する。
