# ADR 0001: 文書言語の運用

- 旧決定日: 2026-06-12（2026-06-13採択）
- 旧方針: 日英の並列管理
- 現在の状態: 2026-10-14のユーザー指示により旧方針を置換

## 現在の決定

ユーザーの「md系は日本語だけでいい」という指示に基づき、現用文書は日本語を正本とする。英語版の追加・同期は行わない。

概要はルートの `README.md`、詳細は `docs/ja/`、パッケージの責務は各パッケージの `README.md` に置く。旧英語版と旧言語選択スタブは日本語への互換入口として残す。

現在の起動手順、実装の説明、過去の計画・実測記録を分離する。過去の証跡は当時の結果を保持し、未着手・予定を現在の状態に読み替えない。

## 旧決定の経緯

以前は `docs/ja/` と `docs/en/` に本文を複製し、旧URLに言語選択スタブを置く方式を採った。外部閲覧者向けの英語版を維持する目的だったが、更新対象が増え、実装・運用手順・ステータスの不一致が残った。

今回の指示で日英同期の義務を終了する。旧本文の詳細はGit履歴に残る。今回の作業以前にローカル変更があったMarkdownは `/tmp/whill-md-backup-20261014/` に退避している。このバックアップは当該PCでの一時保管であり、リポジトリの再現に必要な配布物ではない。
